---
title: "teleop"
description: "Python-first teleoperation API for high-rate robot control"
---

The `rfx.teleop` module provides a high-rate teleoperation runtime for SO-101 robots with async camera streams, data recording, and transport integration.

## run

Run a teleoperation session.

```python
rfx.teleop.run(
    arm: ArmPairConfig | Sequence[ArmPairConfig],
    *,
    logging: bool = False,
    rate_hz: float | None = None,
    duration_s: float | None = None,
    cameras: Sequence[CameraStreamConfig] | None = None,
    transport: Any | None = None,
    data_output: str | Path | None = None,
    lineage: str | None = None,
    scale: str | None = None,
    format: str = "native",
    metadata: Mapping[str, Any] | None = None,
    otel: bool = False,
    otel_exporter: str = "console",
    otel_sample_every: int = 100,
    otlp_endpoint: str | None = None,
) -> RecordedEpisode | dict[str, Any] | None
```

<ParamField path="arm" type="ArmPairConfig | Sequence[ArmPairConfig]" required>
  Arm pair configuration(s)
</ParamField>

<ParamField path="logging" type="bool" default="False">
  Enable live per-loop movement trace in terminal
</ParamField>

<ParamField path="rate_hz" type="float | None" default="None">
  Control loop rate in Hz
</ParamField>

<ParamField path="duration_s" type="float | None" default="None">
  Duration to run in seconds. If None, runs until keyboard interrupt.
</ParamField>

<ParamField path="cameras" type="Sequence[CameraStreamConfig] | None" default="None">
  Camera configurations for recording
</ParamField>

<ParamField path="transport" type="Any | None" default="None">
  Transport configuration for data publishing
</ParamField>

<ParamField path="data_output" type="str | Path | None" default="None">
  Directory to record data. If None, recording is disabled.
</ParamField>

<ParamField path="lineage" type="str | None" default="None">
  Lineage metadata for the recording
</ParamField>

<ParamField path="scale" type="str | None" default="None">
  Scale metadata for the recording
</ParamField>

<ParamField path="format" type="str" default="native">
  Export format: "native", "mcap", or "lerobot"
</ParamField>

<ParamField path="metadata" type="Mapping[str, Any] | None" default="None">
  Additional metadata for the recording
</ParamField>

<ParamField path="otel" type="bool" default="False">
  Enable OpenTelemetry tracing
</ParamField>

<ParamField path="otel_exporter" type="str" default="console">
  OpenTelemetry exporter type
</ParamField>

<ParamField path="otel_sample_every" type="int" default="100">
  Sample telemetry every N iterations
</ParamField>

<ParamField path="otlp_endpoint" type="str | None" default="None">
  OTLP endpoint for telemetry export
</ParamField>

<ResponseField name="return" type="RecordedEpisode | dict[str, Any] | None">
  Recorded episode if data_output is set, otherwise None
</ResponseField>

### Example

```python
import rfx.teleop

arm = rfx.teleop.so101(
    leader_port="/dev/ttyACM0",
    follower_port="/dev/ttyACM1"
)

rfx.teleop.run(arm, data_output="recordings", duration_s=60.0)
```

## so101

Beginner-friendly SO-101 arm spec factory.

```python
rfx.teleop.so101(
    config: str | Mapping[str, Any] | None = None,
    **kwargs: Any
) -> ArmPairConfig
```

<ParamField path="config" type="str | Mapping[str, Any] | None" default="None">
  Configuration dictionary or file path
</ParamField>

<ParamField path="kwargs" type="Any">
  Additional configuration parameters (name, leader_port, follower_port)
</ParamField>

<ResponseField name="return" type="ArmPairConfig">
  Configured arm pair
</ResponseField>

### Example

```python
import rfx.teleop

# Auto-discovery
arm = rfx.teleop.so101()

# Explicit ports
arm = rfx.teleop.so101(
    leader_port="/dev/cu.usbmodemA",
    follower_port="/dev/cu.usbmodemB"
)

# From dict
arm = rfx.teleop.so101({
    "name": "main",
    "leader_port": "/dev/ttyACM0",
    "follower_port": "/dev/ttyACM1"
})
```

### Example

```python
from rfx.teleop import BimanualSo101Session
from rfx.teleop.config import TeleopSessionConfig

session = BimanualSo101Session.from_single_pair(
    leader_port="/dev/ttyACM0",
    follower_port="/dev/ttyACM1"
)

with session:
    episode = session.record_episode(duration_s=30.0, label="demo")
    print(f"Recorded {len(episode.control_steps)} control steps")
```

## LoopTimingStats

Loop timing summary for jitter and overrun analysis.

```python
@dataclass(frozen=True)
class LoopTimingStats:
    iterations: int
    overruns: int
    target_period_s: float
    avg_period_s: float
    p50_jitter_s: float
    p95_jitter_s: float
    p99_jitter_s: float
    max_jitter_s: float
```

<ResponseField name="iterations" type="int">
  Total number of control loop iterations
</ResponseField>

<ResponseField name="overruns" type="int">
  Number of iterations that exceeded the target period
</ResponseField>

<ResponseField name="target_period_s" type="float">
  Target period in seconds
</ResponseField>

<ResponseField name="avg_period_s" type="float">
  Average actual period in seconds
</ResponseField>

<ResponseField name="p50_jitter_s" type="float">
  Median jitter in seconds
</ResponseField>

<ResponseField name="p95_jitter_s" type="float">
  95th percentile jitter in seconds
</ResponseField>

<ResponseField name="p99_jitter_s" type="float">
  99th percentile jitter in seconds
</ResponseField>

<ResponseField name="max_jitter_s" type="float">
  Maximum jitter in seconds
</ResponseField>
